# GP-200 Tone Maker Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a backend-first GP-200 tone maker page that submits form input to FastAPI and displays deterministic patch JSON.

**Architecture:** FastAPI owns validation and rule-based GP-200 patch generation through typed Pydantic models. The frontend keeps logic thin: collect form values, call the backend through a typed client, and render loading, error, and success states.

**Tech Stack:** Next.js App Router, React Client Components, TypeScript, Vitest, React Testing Library, FastAPI, Pydantic, pytest.
